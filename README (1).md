# Brain Tumor Detection (YOLOv8n / YOLOv10n)

Детекция и классификация опухолей головного мозга (glioma, meningioma, pituitary) на MRI-снимках. Сравнение архитектур YOLOv8n и YOLOv10n, оптимизаторов, гиперпараметров и стратегий аугментации данных.

Работа выполнена в рамках практического задания по курсу «Нейросети», НГТУ.

## Датасет

| Класс | Train | Val | Test |
|---|---|---|---|
| BrainTumor | 2144 | 612 | 308 |

Разбиение: 70% train / 20% val / 10% test. Аннотированные МРТ-изображения для задачи детекции трёх типов опухолей: glioma, meningioma, pituitary.

## Стек

Python, PyTorch, Ultralytics (YOLOv8n, YOLOv10n), OpenCV, pandas, matplotlib, seaborn

## Методология

1. **Сравнение оптимизаторов** — SGD, Adam, AdamW на обеих моделях.
2. **Подбор гиперпараметров** — встроенный tuner Ultralytics, поиск по `optimizer` × `lr0`.
3. **Сравнение стратегий аугментации** — 4 конфигурации: без аугментаций, стандартные + mixup, стандартные + copy-paste, только стандартные.
4. **Оценка** — Precision, Recall, mAP50, mAP50-95, confusion matrix.

## Результаты

### Сравнение оптимизаторов (30 эпох, батч 4)

**YOLOv8n**

| Optimizer | P | R | mAP50 | mAP50-95 |
|---|---|---|---|---|
| SGD | 0.858 | 0.821 | 0.882 | 0.650 |
| Adam | 0.809 | 0.855 | 0.890 | 0.632 |
| AdamW | 0.855 | 0.869 | **0.907** | **0.676** |

**YOLOv10n**

| Optimizer | P | R | mAP50 | mAP50-95 |
|---|---|---|---|---|
| SGD | 0.858 | 0.780 | 0.870 | 0.642 |
| Adam | 0.808 | 0.802 | 0.851 | 0.633 |
| AdamW | 0.814 | 0.803 | 0.864 | 0.635 |

Adam исключён из дальнейших экспериментов: близок по сути к AdamW (дублирование результата) и на обеих моделях показал промежуточный результат.

### Подбор гиперпараметров (optimizer × lr0)

| Модель | Лучшая конфигурация | mAP50 |
|---|---|---|
| YOLOv8n | SGD, lr0=0.01 | 0.9164 |
| YOLOv10n | AdamW, lr0=0.001 | 0.8819 |

YOLOv8n (классическая свёрточная архитектура) лучше сходится на высоком learning rate с SGD. YOLOv10n c PSA-блоками (Partial Self-Attention) чувствителен к резким изменениям весов — здесь лучше работает AdamW с адаптивным масштабированием градиентов.

### Сравнение аугментаций

| Тест | YOLOv8n mAP50 | YOLOv10n mAP50 |
|---|---|---|
| Без аугментаций | 0.858 | 0.785 |
| Стандартные + mixup | **0.921** | **0.841** |
| Стандартные + copy-paste | 0.908 | 0.841 |
| Только стандартные | 0.908 | 0.853 |

Лучший результат — стандартный набор аугментаций (hsv, translate, scale, fliplr, mosaic) + mixup: увеличивает разнообразие обучающих примеров и снижает переобучение на датасете такого размера.

### Итоговая лучшая модель

**YOLOv8n, SGD, lr0=0.01, аугментации: стандартные + mixup**

| Class | P | R | mAP50 | mAP50-95 |
|---|---|---|---|---|
| All | 0.869 | 0.848 | 0.921 | 0.666 |
| Glioma | 0.771 | 0.673 | 0.830 | 0.471 |
| Meningioma | 0.924 | 0.952 | 0.970 | 0.811 |
| Pituitary | 0.911 | 0.920 | 0.964 | 0.717 |

Наиболее сложный класс — glioma (наименьшая mAP): опухоль этого типа менее выражена по контуру на снимке, из-за чего чаще путается с фоном (см. confusion matrix — 61–78% ложных срабатываний фона классифицируются как glioma).

## Общий вывод

- YOLOv8n стабильно превосходит YOLOv10n на этом датасете и объёме обучения — более сложная архитектура YOLOv10n с PSA-блоками требует большего числа эпох для полной сходимости.
- Аугментации типа mixup дают наибольший прирост качества на датасете среднего размера за счёт снижения переобучения.
- Оптимальная связка гиперпараметров зависит от архитектуры: SGD с высоким lr для классических сверточных сетей, AdamW с низким lr для архитектур с self-attention блоками.
